Foundation

Synta — The Cryptographic Engine

Core Library

Native Rust ASN.1 DER/BER codec with zero-copy decoding. Integer, OID, BitString, and all X.690 primitives. No C dependencies for parsing.

synta

Certificate Operations

X.509 certificate issuance, PKCS#10 CSR parsing, CRL generation, OCSP. Post-quantum composite signatures via OpenSSL 3.5+ OQS provider.

synta-certificate

Path Validation

X.509 certification path validation — trust anchor resolution, name constraints, key usage checking. Powers mTLS verification.

synta-x509-verification

MTC Transparency

Merkle tree log primitives — append-only disk-backed log, leaf hashing, tree root computation, checkpoint construction, cosignature handling.

synta-mtc

ACME CA

Akamu — Self-Hosted Certificate Authority

Full ACME v2

RFC 8555 — accounts, orders, authorizations, challenges, revocation. Five challenge types: http-01, dns-01, tls-alpn-01, dns-persist-01, onion-csr-01.

CRDT Clustering

Multi-node gossip replication with ML-KEM-768 encrypted, CMS-signed envelopes. Automatic state convergence — eventually consistent.

Certificate Profiles

Pluggable providers: built-in TOML, Dogtag PKI via REST, FreeIPA/IPAThinCA via LDAP. Profile-driven issuance including MTC format.

HSM / PKCS#11

CA keys in hardware tokens. Key material never leaves the HSM.

Web UI + Admin CLI

React dashboard, akamuctl CLI, mTLS or Kerberos RBAC.

23 RFCs Implemented

STAR, ARI, CAA, subdomain auth, Tor .onion, renewal info, and more.

EST Enrollment

Kipuka — Certificate Enrollment Server

EST (RFC 7030)

All six operations — cacerts, simpleenroll, simplereenroll, fullcmc, serverkeygen with KRA key escrow, and csrattrs. STAR auto-renewal integration.

CMP (RFC 4210/9810)

MAC-based and signature-based protection. IR, CR, KUR, and RR requests. Served at /.well-known/cmp.

EST-over-CoAP (RFC 9483)

IoT and constrained devices via DTLS 1.2/1.3 transport. Block-wise transfer, compressed URI paths, session resumption.

Multi-CA HA

Active-passive, round-robin, weighted, and latency-based failover with circuit breakers.

Dogtag Integration

Profile enrollment, Full CMC passthrough, KRA key escrow, TPS smart card support.

21 RFCs • 129 Assertions

CMS-EST, CSR templates (RFC 9908), OTP auth, GSSAPI/Kerberos, mTLS with OCSP.

Quantum Resistant

Post-Quantum Ready — From Day One

ML-DSA Signing (FIPS 204)

ML-DSA-44/65/87 for account keys, certificates, and TLS authentication. Composite hybrid signatures: ML-DSA + RSA, ECDSA, or Ed25519 for migration.

ML-KEM Encapsulation (FIPS 203)

ML-KEM-768 key exchange in gossip protocol encryption. Post-quantum composite TLS for server authentication.

HSM / PKCS#11

PQC keys in hardware tokens. PKCS#11 v3.2 mechanisms.

CNSA 2.0

Aligned with NSA timeline. OpenSSL 3.5+ OQS provider.

MTC Transparency

Batch signing amortizes PQ costs. One sig covers thousands of certs.

Enterprise Ready

Deep Integration, Flexible Deployment

GSSAPI authentication for ACME EAB. LDAP certificate profile loading. RHEL IdM co-deployment with IPA thin CA support.

Multi-Database

Containers & K8s
